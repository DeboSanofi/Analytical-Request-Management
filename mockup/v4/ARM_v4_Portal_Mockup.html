Reason
A request has one or more methods; a method links to samples and, after analysis, to result files in LDI. A worklist groups methods of several requests.

Glossary

TermDefinition (proposed, to be agreed)
RequestContainer for all analyses ordered for one batch. Identified by the ARM ID.
MethodOne analytical technique within a request, handled by one lab.
Task Count (dashboard)Number of methods started in the period. A task with LCMS and NMR counts once per method.
Status: Ready for analystRequest accepted and complete; no worklist yet.
Status: Data in LDIAt least one result file for the method is stored in the Lab Data Inventory.
Status: Results registeredResults and attachments are registered in ChemDiary.
LDILab Data Inventory: read-only storage of raw data and results (AWS).
LEAPLab automation that moves requests, worklists and results between systems.
